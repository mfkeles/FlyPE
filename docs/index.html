FlyPE

Behaviour detection in Drosophila video with a YOLO11 object detector.

Code on GitHub

Overview

FlyPE fine-tunes a YOLO11-l detector to localise a fly and classify its behaviour in each video frame. The detector is trained on motion-heatmap frames, in which recent movement is colour-coded on top of the grey-scale image, so that behaviours that differ only in small movements of the proboscis or legs remain separable.

  • 0ProbPumping
  • 1Moving
  • 2Grooming
  • 3Feeding
  • 4Quiescent
  • 5HaltereSwitch

The repository currently contains the training code. Analysis scripts will be added as individual, self-contained scripts.

Install

FlyPE uses uv. Pick the PyTorch runtime that matches your machine.

git clone https://github.com/mfkeles/FlyPE.git
cd FlyPE
uv sync --extra cuda    # Windows/Linux with an NVIDIA GPU
uv sync --extra metal   # macOS on Apple Silicon
uv sync --extra cpu     # CPU only

Train

uv run flype-train --data /path/to/data.yaml --project runs --device 0

The run is written to runs/flype/, with the best checkpoint at runs/flype/weights/best.pt. Training expects a standard Ultralytics detection dataset; see the README for the layout.

Recipe

ModelYOLO11-l, COCO-pretrained
Image size800 px, rectangular batches
Schedule200 epochs, early stopping with 100-epoch patience
Batch size16
Seed0
Colour augmentationBrightness only; hue and saturation off, so the colour-coded motion channel is preserved
